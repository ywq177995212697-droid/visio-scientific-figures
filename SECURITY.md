# Security Policy

## Supported Versions

The `main` branch receives security and safety fixes.

## Reporting a Vulnerability

Please open a private security advisory on GitHub or contact the maintainer through the repository profile. Do not publish private manuscript content, unpublished figures, credentials, or proprietary Visio files in public issues.

## Data Safety

This repository is designed for open-source-safe examples only. When using the skill with real research projects:

- Keep confidential manuscripts, raw `.docx` files, unpublished figures, and proprietary images outside public examples.
- Store generated image assets locally unless you have permission to share them.
- Review `.vsdx`, `.png`, `.emf`, and `quality_report.md` before committing them.
- Remove user-specific absolute paths from specs and reports before publishing.
